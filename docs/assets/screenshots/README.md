# 截图素材

这里的图片用于 README 和 GitHub Pages，全部来自真实构建与本机 DevEco Code CLI。

| 文件 | 内容 |
|---|---|
| `overview.jpg` | 主界面：工作区、会话、工具调用、审查回复与变更列表 |
| `changes.jpg` | 变更面板：文件筛选与统一 diff 查看器 |

## 生成约定

- 使用临时演示工作区和演示会话，不截取私有仓库、真实会话、凭据、用户目录或公司内部项目；
- 设备截图只保留公开可展示的机型、系统版本和页面，不包含通知内容、账号信息或聊天记录；
- 截图保存为 2x Retina 窗口画面，缩放到最长边 1800 像素并用 JPEG 质量 86 输出；
- README 使用 `docs/assets/screenshots/`，官网使用 `website/assets/screenshots/`，两份内容保持一致；
- 更新界面后重新截取并同步修改本表和相关文档中的 alt 文案。
