# 功能说明

本文描述当前版本的稳定行为。界面细节可能随版本调整，但 CLI 交互边界和数据位置应保持
与[架构说明](architecture.md)一致。

## 整体布局

| 区域 | 内容 |
|---|---|
| 标题栏 | 无系统标题栏，红黄绿灯内嵌；左侧是侧栏开关和当前会话标题，右侧是导出、任务概览与右栏开关；空白处可拖动窗口，双击缩放 |
| 左栏 | 工作区搜索、视图设置、新建会话；可同时展开多个工作区，显示相对时间和生成状态；底部显示唯一的 CLI 服务状态与设置入口 |
| 主区 | 对话流、待办/子代理进度条、权限审批卡片和 Composer；正文直接从标题栏下方开始 |
| 状态栏 | 当前工作区、轮次、Token 总消耗和生成速度；输入/输出/推理/缓存/成本在悬浮提示中 |
| 右栏 | 变更、文件、任务、设备四个标签；可折叠、拖动调宽并长按排序 |
| 设置与快捷键 | `⌘,` 打开设置，`⌘/` 打开快捷键面板；均为独立模态界面 |

应用图标由 `src-tauri/icons/source.png` 生成；界面品牌位、助手头像、启动页和 favicon
使用同一套 `AppIcon` 资源。

## 工作区与会话

- **懒加载**：展开工作区时才请求会话列表；多个工作区可以同时展开。
- **展开与收起**：点击工作区行翻转该目录自己的展开状态；点击已展开的工作区直接收起，
  不会切换当前工作区或跳到最近会话；点击工作区只影响展开状态，只有点击会话或新建会话
  才会切换当前对话。
- **新会话**：先进入草稿态，可选择已有工作区或调用系统目录面板新建工作区；发送首条消息时
  才创建绑定该目录的会话。会话有内容后不可再切换工作区。
- **侧栏**：工作区行显示文件夹图标与名称，不保留选中态，只在悬停时显示背景；键盘聚焦使用
  行内描边，当前工作区由底部状态栏标识。会话标题与工作区名称左对齐，当前会话只用圆角底块
  背景区分，生成状态在顶栏显示。
- **分页**：每个工作区默认显示最近 5 条会话，可在“展开更多”和“收起”之间切换；默认条数、
  排序和归档可见性可在视图设置中修改并持久化。
- **移除工作区**：只从侧栏隐藏，不删除目录、CLI 注册表或历史会话；重新选择同一目录会恢复。
- **会话管理**：悬停可重命名、归档或删除；重命名也支持双击标题，删除需要行内二次确认。
- **归档**：归档通过 CLI 元数据完成；归档会话默认从侧栏隐藏，可在视图设置中显示并取消归档。
- **全局搜索**：搜索框带 300ms 防抖，并行查询所有工作区，点击结果直接跳转。
- **停止生成**：运行中的任务显示“停止”，可中断由本应用、外部客户端或 CLI 启动的任务。

## Composer 与消息发送

- 默认两行、最多四行，超出后内部滚动；底部工具栏保持单行，窄窗口优先省略模型名。
- 模型菜单只显示未弃用、已启用且在“设置 → 账号与模型”中勾选的模型；选择结果随消息发送，
  不修改 CLI 全局配置。
- Agent 菜单来自 `/agent` 的 primary 列表；推理档位来自模型 variants，默认选最高档。
- 输入 `/` 打开命令与技能列表，支持方向键、Enter 和 Esc。
- `@` 引用工作区文件，最多 8 个。路径含空格时写成 `@"path with space"`，发送时使用
  `file://` file part，由 CLI 自行读盘并合成 Read 调用。
- 附件最多 4 个，单个不超过 8MB；支持文件选择和剪贴板截图粘贴。图片转为 data URL，
  文本类附件由 CLI 内联。
- 发送失败会把原文放回输入框。发送统一走 `prompt_async`，不使用会等待整个 Agent loop 的
  同步消息接口。

## 对话流

- Markdown 支持 GFM；正文中的 `@` 引用和文件链接可在右栏打开。
- 连续助手步骤共用左侧时间线；相邻工具调用合并成紧凑列表，完成、执行中和失败状态可区分。
- 思考过程默认折叠并显示耗时，生成中的正文有脉冲状态。
- 聊天顶部显示待办完成进度、当前进行项和运行中的子代理数量。
- `task` 与 `subtask` 渲染为子代理卡片，展示 Agent、耗时、待办进度和最近活动；点击后进入
  右栏“任务”。
- 权限审批以卡片形式出现在对话流末尾：允许一次、总是允许、拒绝。CLI 侧权限策略为 `allow`
  时不会产生审批请求。
- 消息可复制正文和时间；代码块、行内代码、链接和工具输入/输出有独立右键菜单。

## 右栏

### 变更

- 优先读取 `/session/{id}/diff` 的会话快照；为空时回退到当前 Git 工作区 diff。
- 非 Git 项目没有 diff 时显示明确空态，而不是错误弹窗。
- 任务概览显示 ahead/behind、暂存/未暂存、未跟踪文件和增删行数。
- 提交和推送是两个显式按钮，作用于当前工作区全部改动（包括未跟踪文件）。提交信息留空时，
  应用通过隔离的 `session.btw` Agent 生成后直接提交；推送优先跟随 upstream，没有 upstream
  时回退到 `origin`。

### 文件

- 按目录浏览，支持进入、返回上级、搜索和文本/Markdown 预览。
- 图片、PDF、音频和视频直接内嵌；Markdown 可在预览和源码间切换。
- Office、iWork、HEIC 等格式调用 macOS Quick Look 生成首屏缩略图。
- 无法预览或过大的文件提供“用默认应用打开”。
- 消息中的 `@` 文件链接与文件面板共用预览路径。

### 任务

- 待办显示完成、进行中、取消和高优先级状态。
- 子代理通过 `metadata.sessionId` 与 `/session/{id}/children` 关联。
- 子会话消息、状态和待办事件并入当前任务视图；点击子代理可查看任务说明、最近活动和子会话
  待办。

### 设备

- 通过本机 `hdc` 发现 HarmonyOS 设备，调用 `snapshot_display` 抓取单帧。
- 支持刷新、复制、另存和附加到当前对话；截图保存在应用数据目录，不随安装包分发 hdc。
- 多设备时可选择目标；单设备时合并重复选择行。
- 收起或切换标签后复用内存中的设备列表、截图和 JPEG 字节，只有刷新或重新扫描才重抓。
- “充电时保持亮屏”在应用运行期间每 5 秒检查充电状态，充电时持有 PowerManager keep-on 锁；
  关闭开关或正常退出时释放。

右栏宽度最小 320px、最大为窗口宽度的一半；拖动边缘调宽，双击复位。标签长按约 320ms 后可
拖动排序，顺序保存在 localStorage。

## 设置

`⌘,` 打开，`Esc` 关闭，`⌘S` 保存，Tab 焦点锁在面板内。左侧分类固定，右侧详情独立滚动，
切换分类不会丢弃未保存修改。

| 分类 | 内容 | 生效方式 |
|---|---|---|
| 外观 | 主题、界面字体、代码字体、菜单栏图标样式与常驻显示 | 主题/字体即时；菜单栏保存后即时 |
| 账号与模型 | 登录/实名、配额、默认/小模型、UI 校验模型、模型可见性、Provider 与最近 30 天用量 | 模型勾选即时；其余只读 |
| Agent 与权限 | 默认/当前 Agent、配置覆盖与权限规则摘要 | 只读 |
| 扩展 | MCP 状态与重连/断开、Skills 搜索与启停、Plugins | 操作即时 |
| CLI 与服务 | CLI 路径、有效配置、配置来源、端口偏好与本地服务口令 | 需重启 |
| 通知 | 总开关、授权/完成/失败/阶段、前台静音 | 即时 |
| 诊断 | CLI/应用版本、服务地址、后端状态、日志、应用配置与重启应用 | — |

桌面端不直接改写 `~/.config/deveco/deveco.jsonc`。账号、模型、Agent 与扩展信息通过 CLI
HTTP API 读取；Provider/MCP 凭据值不会渲染，只显示来源、状态和是否已配置。

## macOS 集成

- 原生菜单：`⌘N` 新建会话、`⌘E` 导出、`⌘,` 设置、`⌘⇧B` 切换右栏、`⌘/` 快捷键、
  `⌘R` 重载界面。
- 关闭主窗口默认隐藏到菜单栏，不退出 serve；托盘提供显示/隐藏、设置、置顶、日志、诊断、
  重启服务和退出。
- 菜单栏支持单色 template 与彩色图标，可常驻或仅在窗口隐藏时显示；待授权数量显示在图标旁。
- 系统通知覆盖授权、完成、失败和阶段四类，支持前台静音和按会话去抖。
- 窗口大小与位置自动恢复，原生窗口标题跟随“会话 · 项目”。
- 全局右键菜单覆盖工作区、会话、消息、代码、工具、文件、diff、输入框和空白区域。

## 导出、查找与附件

- `⌘E` 调用 `deveco export` 导出当前会话 JSON，写至应用数据的 `exports/` 并在 Finder 中定位。
- `⌘F` 打开会话内查找，Enter/Shift+Enter 跳转，Esc 关闭。
- 消息附件可点击预览；图片和文本在应用内显示，其他类型提供下载。
- 侧栏、标题栏、文件列表和工具摘要等操作标签不产生文本选区；消息正文、代码、diff 和预览
  仍可正常选中复制。
