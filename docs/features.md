# 功能说明

本文描述当前版本的稳定行为。界面细节可能随版本调整，但 CLI 交互边界和数据位置应保持
与[架构说明](architecture.md)一致。

## 整体布局

| 区域 | 内容 |
|---|---|
| 标题栏 | 无系统标题栏，红黄绿灯内嵌；左侧是侧栏开关，当前会话标题与工作区左缘对齐，右侧依次是任务概览、终端与右栏开关；空白处可拖动窗口，双击缩放 |
| 左栏 | 工作区搜索、视图设置、新建会话；可同时展开多个工作区，显示相对时间和生成状态；底部显示唯一的 CLI 服务状态与设置入口 |
| 主区 | 对话流、待办/子代理进度条、权限审批卡片、Composer 和可收起的底部终端；正文直接从标题栏下方开始 |
| 状态栏 | 当前工作区、轮次、Token 总量与缓存命中、上下文占用、输出速度（TPS）；未缓存输入/输出/推理/缓存/成本在悬浮提示中 |
| 右栏 | 变更、文件、任务、设备四个标签；可折叠、拖动调宽并长按排序 |
| 设置与快捷键 | `⌘,` 打开设置，`⌘/` 打开快捷键面板；均为独立模态界面 |

应用图标由 `src-tauri/icons/source.png` 生成；界面品牌位、助手头像、启动页和 favicon
使用同一套 `AppIcon` 资源。

## 工作区与会话

- **懒加载**：展开工作区时才请求会话列表；多个工作区可以同时展开。
- **展开与收起**：点击工作区行翻转该目录自己的展开状态；点击已展开的工作区直接收起，
  不会切换当前工作区或跳到最近会话；点击工作区只影响展开状态，只有点击会话或新建会话
  才会切换当前对话。
- **新会话**：先进入草稿态，可选择已有工作区或调用系统目录面板新建工作区；发送首条消息时
  才创建绑定该目录的会话。会话有内容后不可再切换工作区。
- **侧栏**：工作区行显示文件夹图标与名称，不保留选中态，只在悬停时显示背景；键盘聚焦使用
  行内描边，当前工作区由底部状态栏标识。会话标题与工作区名称左对齐，当前会话只用圆角底块
  背景区分；执行中的会话在标题前显示加载指示，执行结束但尚未打开查看的会话显示未读圆点，
  打开会话后圆点消失。打开或重连会话时用 `/session/status` 校准当前会话的执行状态。
- **分页**：每个工作区默认显示最近 5 条会话，可在“展开更多”和“收起”之间切换；默认条数、
  排序和归档可见性可在视图设置中修改并持久化。
- **移除工作区**：只从侧栏隐藏，不删除目录、CLI 注册表或历史会话；重新选择同一目录会恢复。
- **会话管理**：悬停可重命名、归档或删除；重命名也支持双击标题，删除需要行内二次确认。
- **归档**：归档通过 CLI 元数据完成；归档会话默认从侧栏隐藏，可在视图设置中显示并取消归档。
- **全局搜索**：搜索框带 300ms 防抖，并行查询所有工作区，点击结果直接跳转。
- **停止生成**：运行中的任务显示“停止”，可中断由本应用、外部客户端或 CLI 启动的任务。

## Composer 与消息发送

- 默认两行、最多四行，超出后内部滚动；底部工具栏保持单行，窄窗口优先省略模型名。
- 模型菜单只显示未弃用、已启用且在“设置 → 账号与模型”中勾选的模型；选择结果随消息发送，
  不修改 CLI 全局配置。
- Agent 菜单来自 `/agent` 的 primary 列表；推理档位来自模型 variants，默认选最高档。
- 输入 `/` 打开命令与技能列表，支持方向键、Enter 和 Esc。
- `@` 引用工作区文件，最多 8 个。路径含空格时写成 `@"path with space"`，发送时使用
  `file://` file part，由 CLI 自行读盘并合成 Read 调用。
- 附件最多 4 个，单个不超过 8MB；支持文件选择和剪贴板截图粘贴。图片转为 data URL，
  文本类附件由 CLI 内联。
- 发送失败会把原文放回输入框。发送统一走 `prompt_async`，不使用会等待整个 Agent loop 的
  同步消息接口。

### 历史用户消息编辑

- 用户消息悬停操作区显示“编辑”，右键菜单也提供“编辑消息”。会话执行中、存在排队/待确认
  消息，或消息包含内联命令等非 text/file part 时不可编辑，并会说明原因。
- 编辑在原气泡位置展开：正文可改，原上传附件以 chip 展示并可移除；正文中的 `@路径` 保留，
  发送时按新文本重新生成 `file://` file part。编辑器不提供新的 @ 弹层，也不新增附件。
- 重新发送沿用原消息的 Agent、模型和推理档位。第一次提交会先显示影响范围：这条消息及其后
  N 条消息将被删除，工作区会还原到这条消息之前；确认后才调用
  `POST /session/{id}/revert`，随后走 `prompt_async`。CLI 在下一次 prompt 的 cleanup 中
  永久删除回滚消息。
- 编辑期间底部 Composer 保留草稿但禁用发送；`⌘Enter` 提交，`Esc` 先退出确认再取消编辑，
  中文输入法组字期间不触发快捷键。切换会话或工作区会放弃未提交的编辑草稿。
- 若 prompt 失败，应用会读取会话状态并尝试 `unrevert` 恢复原消息；如果 cleanup 已经执行，
  编辑器保留在本地快照上，可直接重试。取消编辑后按服务器状态刷新。
- 外部客户端或 CLI 设置的 revert 会隐藏边界后的消息，并在对话流底部显示“已回滚 N 条消息”；
  点击“恢复消息”会调用 `unrevert`，同时恢复消息与工作区文件。存在未恢复的 revert 时，
  底部 Composer 直接发送会先确认是否永久丢弃这些回滚消息。

### 执行中的排队与引导

- 执行中按 Enter 把当前输入加入排队，按 `⌘Enter` 直接作为引导消息发送。空闲且队列
  未暂停时，新消息加入队尾；队列已暂停时，新消息直接作为普通消息发送，旧队列保持暂停。
- 排队按会话 FIFO，最多 20 条，附件总量不超过 64MB。输入框上方托盘显示待发送内容，
  支持“引导/发送”、编辑、删除和失败重试；编辑只在输入框为空时执行，并恢复引用和附件。
- 当前轮 `session.idle` 后自动发送队首，每条排队消息作为独立新一轮；`session.error` 或
  用户点停止时暂停队列并保留内容，点“继续发送”恢复。
- 引导消息带客户端生成的 `messageID`，优先在当前任务的下一个模型步骤生效；正在执行的
  工具会先完成，不会硬打断。若当前轮已经结束，应用会补一条不可见的 synthetic 继续消息，
  自动开启新一轮，原引导内容不会重复写入。
- 引导消息在对话气泡上方显示“引导”标记；输入区状态行显示“等待下一步 / 已暂停 / 未送达”，
  未送达时可重试或忽略。

## 对话流

- Markdown 支持 GFM；正文中的 `@` 引用和文件链接可在右栏打开。
- 连续助手步骤共用左侧时间线；相邻工具调用合并成紧凑列表，完成、执行中、失败和已中断状态
  可区分。CLI 进程异常终止后残留的 `running`/`pending` 工具和未结束的思考记录显示为已中断。
- 思考过程默认折叠并显示耗时，生成中的正文有脉冲状态。
- 聊天顶部显示待办完成进度、当前进行项和运行中的子代理数量。
- `task` 与 `subtask` 渲染为子代理卡片，展示 Agent、耗时、待办进度和最近活动；点击后进入
  右栏“任务”。
- 权限审批以卡片形式出现在对话流末尾：允许一次、总是允许、拒绝。CLI 侧权限策略为 `allow`
  时不会产生审批请求。
- 消息可复制正文和时间；代码块、行内代码、链接和工具输入/输出有独立右键菜单。

## 底部终端

- 点击标题栏右侧动作组中间的终端图标或按 `⌘J` 展开/收起；面板高度可拖动调整，双击复位，并记住上次高度。
- 终端在当前工作区目录启动本地 Shell；没有工作区时从用户主目录启动。终端使用 CLI 的
  `/pty` 会话，不是桌面端另起的子进程。
- 支持常规 Shell 输入、输出、滚动和选中复制；拖动窗口或调整面板高度后会自动同步 PTY 尺寸。
- 头部显示 Shell、目录和运行状态，可重启终端或收起面板；重启会先结束旧会话，再按当前尺寸
  新建一个。关闭面板会结束该终端会话。
- 输出经 Rust 维持的 WebSocket 转成 Tauri 事件，前端不接触 CLI 端口、口令或连接票据；
  CLI 不可用、会话退出或连接中断时显示失败原因和“重新打开”出口。
- 当前每次只保留一个底部终端，不提供多标签或分屏。

## 右栏

### 变更

- 顶部可在「工作区」和「本次会话」之间切换：工作区读取 `/vcs/diff?mode=git`，
  本次会话读取 `/session/{id}/diff`；没有当前会话时自动回退到工作区，不混用两种来源。
- 变更按目录分组并可折叠，目录显示文件数与聚合增删行；文件行显示新增/修改/删除状态徽标。
- 支持按路径筛选、全部展开/收起、手动刷新，以及 `session.diff`、文件监听和会话结束后的自动刷新。
- 点击文件在右栏内查看统一 diff：旧/新行号、`+/-` 标记、hunk 头、增删行配色、横向滚动和
  二进制/无补丁说明；大段未修改内容会折叠为“省略 N 行”，超长补丁只渲染前 4000 行，
  完整补丁仍可复制。
- 非 Git 项目显示明确空态，而不是错误弹窗。
- 任务概览显示 ahead/behind、暂存/未暂存、未跟踪文件和增删行数。
- 提交和推送是两个显式按钮，作用于当前工作区全部改动（包括未跟踪文件）。提交信息留空时，
  应用通过隔离的 `session.btw` Agent 生成后直接提交；推送优先跟随 upstream，没有 upstream
  时回退到 `origin`。

### 文件

- 根目录和展开目录按需加载，按目录优先、自然排序显示文件树；展开状态在工作区会话内保留。
- 支持全库文件/目录搜索（200ms 防抖、最多 200 条）；点击目录会展开祖先目录并滚动定位。
- 默认隐藏 `.gitignore` 命中的忽略项，可用眼部按钮显示；文件行显示工作区变更状态，
  包含变更文件的目录显示聚合数量。
- `/vcs/status` 提供文件状态徽标；状态读取失败不影响文件树浏览。
- 图片、PDF、音频和视频直接内嵌；Markdown 可在预览和源码间切换。
- Office、iWork、HEIC 等格式调用 macOS Quick Look 生成首屏缩略图。
- 预览头部可重新读取当前文件、用默认应用打开或返回原文件树/搜索结果。
- 无法预览或过大的文件提供“用默认应用打开”。
- 消息中的 `@` 文件链接与文件面板共用预览路径。

### 任务

- 待办显示完成、进行中、取消和高优先级状态。
- 子代理通过 `metadata.sessionId` 与 `/session/{id}/children` 关联。
- 子会话消息、状态和待办事件并入当前任务视图；点击子代理可查看任务说明、最近活动和子会话
  待办。

### 设备

- 通过本机 `hdc` 发现 HarmonyOS 设备，调用 `snapshot_display` 抓取单帧。
- 支持刷新、复制、另存和附加到当前对话；截图保存在应用数据目录，不随安装包分发 hdc。
- 多设备时可选择目标；单设备时合并重复选择行。
- 收起或切换标签后复用内存中的设备列表、截图和 JPEG 字节，只有刷新或重新扫描才重抓。
- “充电时保持亮屏”在应用运行期间每 5 秒检查充电状态，充电时持有 PowerManager keep-on 锁；
  关闭开关或正常退出时释放。
- 应用启动时把内嵌 `deveco-desktop-device` skill 安装到 CLI 的全局 skills 目录，并把已定位的
  `HDC` 路径注入 serve 环境。Agent 因此可以发现设备、截图、读取布局树、点击/滑动/输入、
  安装启动应用、传输文件和采集设备日志；不依赖桌面端 UI 自动化。
- skill 安装不修改 `deveco.jsonc`。目录带 `.deveco-desktop-managed` 标记，应用只更新自己
  管理的内容；无标记的同名目录会保留。可在“设置 → 扩展”中查看或停用该 skill。

右栏宽度最小 320px、最大为窗口宽度的一半；拖动边缘调宽，双击复位。标签长按约 320ms 后可
拖动排序，顺序保存在 localStorage。

## 设置

`⌘,` 打开，`Esc` 关闭，`⌘S` 保存，Tab 焦点锁在面板内。左侧分类固定，右侧详情独立滚动，
切换分类会保留草稿；离开 CLI 配置页、切换配置范围或关闭设置前，有未保存修改时会先确认。

| 分类 | 内容 | 生效方式 |
|---|---|---|
| 外观 | 主题、界面字体、代码字体、菜单栏图标样式与常驻显示 | 主题/字体即时；菜单栏保存后即时 |
| 账号与模型 | 登录/登出、产品协议、实名与配额、默认/小/UI 校验模型、模型可见性、Provider/模型 CRUD、最近 30 天用量 | 模型勾选即时；配置保存后重载 |
| Agent 与权限 | 默认/当前 Agent、配置型 Agent/Command CRUD、文件型只读、权限规则与 pattern JSON | 保存后重载 |
| 扩展 | MCP 增删改/连接/OAuth、Skills 路径与启停、Plugins 配置 | 操作即时或保存后重载 |
| CLI 与服务 | 内置 CLI 优先开关、CLI 路径、有效配置、全局/项目配置、启动参数、高级 JSONC、备份恢复与 CLI 升级 | 配置保存后重载；启动参数需重启 |
| 通知 | 总开关、授权/完成/失败/阶段、前台静音 | 即时 |
| 诊断 | CLI/应用版本、服务地址、后端状态、日志、应用配置与重启应用 | — |

账号与模型、Agent、扩展和 CLI 页共享“全局 / 当前工作区”配置范围。全局写入
`~/.config/deveco/deveco.jsonc`，项目写入 `.deveco/deveco.jsonc`（或已有根
`deveco.jsonc`）；首次保存会自动创建项目配置。写入前校验文件 hash 并保存备份，写入后
调用 `/instance/dispose` 或 `/global/dispose` 重载；失败时恢复上一版本。Provider、MCP
headers/environment 和 OAuth client secret 默认脱敏，高级编辑器可显式切换明文。
文件型 Agent/Command 只读；Plugin 只编辑配置入口，不执行 npm 安装。

## macOS 集成

- 原生菜单：`⌘N` 新建会话、`⌘,` 设置、`⌘⇧B` 切换右栏、`⌘/` 快捷键、
  `⌘R` 重载界面。
- 关闭主窗口默认隐藏到菜单栏，不退出 serve；托盘提供显示/隐藏、设置、置顶、日志、诊断、
  重启服务和退出。
- 菜单栏支持单色 template 与彩色图标，可常驻或仅在窗口隐藏时显示；待授权数量显示在图标旁。
- 系统通知覆盖授权、完成、失败和阶段四类，支持前台静音和按会话去抖。
- 窗口大小与位置自动恢复，原生窗口标题跟随“会话 · 项目”。
- 全局右键菜单覆盖工作区、会话、消息、代码、工具、文件、diff、输入框和空白区域。

## 查找与附件

- `⌘F` 打开会话内查找，Enter/Shift+Enter 跳转，Esc 关闭。
- 消息附件可点击预览；图片和文本在应用内显示，其他类型提供下载。
- 侧栏、标题栏、文件列表和工具摘要等操作标签不产生文本选区；消息正文、代码、diff 和预览
  仍可正常选中复制。
