# DevEco Code Desktop v0.2.2

发布日期：2026-11-08

## 中文

本版本不改变桌面端的主要交互，重点升级依赖、修复构建兼容性，并补齐仓库自动化与安全
检查。发布流程继续使用 draft-first、`SHA256SUMS.txt`、artifact attestation 和
immutable release。

### 版本内容

- 升级 Tauri 与 Rust 依赖：`tauri-plugin-dialog 2.8.4`、`dirs 7`、
  `tokio-tungstenite 0.30`、`jsonc-parser 0.34`（启用 `serde_json` feature）。
- 升级前端构建依赖：TypeScript `7.0.2`、Vite `8.3.6`、
  `@vitejs/plugin-react 6.2.1`。
- 适配 `tokio-tungstenite` 的 `Utf8Bytes` 文本消息类型，修复 `jsonc-parser`
  的 `serde_json` feature 配置。
- 修复 Node 20 下 Vite 配置加载、`.artifacts` 隐藏目录上传和已退役
  `macos-14` runner 的兼容问题。
- 升级 GitHub Actions：`checkout@v7`、`setup-node@v7`、`upload-artifact@v7`、
  `configure-pages@v6`、`upload-pages-artifact@v5`、`deploy-pages@v5`。
- 仓库自动化：Dependabot 每周分组更新根 npm、UI npm、Cargo 和 GitHub Actions，
  security updates 已启用；CodeQL 扫描 Rust、JavaScript/TypeScript 和 GitHub Actions；
  Dependency Review 阻断高危漏洞；新增 RustSec `cargo audit`、Release readiness 和
  PR 路径标签工作流。
- 仓库规则：`main` 要求 PR、CI、CodeQL 和 Dependency Review；`v*` 标签禁止更新、
  删除和 force push；Release immutability 已启用。
- README 和官网改用真实应用截图，新增主界面、变更 diff、任务概览、HarmonyOS 设备面板
  和底部终端展示；安装页增加真实界面预览。

### 下载

- Apple Silicon：选择文件名带 `aarch64` 的 DMG。
- Intel：选择文件名带 `x64` 的 DMG。
- 两个架构都提供 `DevEco Code` 和 `DevEco Code Offline` 两种包。
- 资产附带 `SHA256SUMS.txt` 和 GitHub artifact attestation；校验方法见
  `docs/installation.md`。

### 安装

1. 打开 DMG，将应用拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用并选择“打开”，或到
   “系统设置 → 隐私与安全性”点击“仍要打开”。
3. Offline 版直接使用内置 CLI；普通版先安装并登录 CLI：

```bash
npm i -g @deveco/deveco-code
deveco providers
```

完整说明见 `docs/installation.md`。

### 已知限制

- macOS 12+，当前只验证 macOS；不提供 Universal 二进制。
- 登录、模型调用和 HarmonyOS 知识库仍需要网络。
- DevEco Studio、HarmonyOS SDK、HDC、模拟器不随应用分发。
- 暂不支持自动更新、Windows 和 Linux。
- 历史消息编辑只支持用户消息及文本/附件内容；发送后不可撤销，文件还原可能覆盖之后的
  未提交修改。
- 保存 CLI 配置会重载实例，正在运行的任务可能被中断。

## English

This release keeps the main desktop interactions unchanged. It focuses on dependency
upgrades, build compatibility fixes, and repository automation and security checks. The
release flow still uses draft-first publishing, `SHA256SUMS.txt`, artifact attestations,
and immutable releases.

### What's new

- Upgraded Tauri and Rust dependencies: `tauri-plugin-dialog 2.8.4`, `dirs 7`,
  `tokio-tungstenite 0.30`, and `jsonc-parser 0.34` with the `serde_json` feature.
- Upgraded frontend build dependencies: TypeScript `7.0.2`, Vite `8.3.6`, and
  `@vitejs/plugin-react 6.2.1`.
- Adapted to the `tokio-tungstenite` `Utf8Bytes` text message type and fixed the
  `jsonc-parser` `serde_json` feature configuration.
- Fixed Vite config loading under Node 20, uploads from the hidden `.artifacts`
  directory, and compatibility with the retired `macos-14` runner.
- Upgraded GitHub Actions: `checkout@v7`, `setup-node@v7`, `upload-artifact@v7`,
  `configure-pages@v6`, `upload-pages-artifact@v5`, and `deploy-pages@v5`.
- Repository automation: Dependabot now groups weekly updates for root npm, UI npm,
  Cargo, and GitHub Actions; security updates are enabled. CodeQL scans Rust,
  JavaScript/TypeScript, and GitHub Actions. Dependency Review blocks high-severity
  vulnerabilities. Added RustSec `cargo audit`, release readiness, and PR path-label
  workflows.
- Repository rules: `main` requires a pull request plus CI, CodeQL, and Dependency
  Review; `v*` tags cannot be updated, deleted, or force-pushed. Release immutability
  is enabled.
- README and the website now use real application screenshots, covering the main
  window, change diffs, task overview, HarmonyOS device panel, and bottom terminal.
  The installation page also includes a real UI preview.

### Downloads

- Apple Silicon: choose the DMG with `aarch64` in its filename.
- Intel: choose the DMG with `x64` in its filename.
- Both architectures include the Standard and Offline packages.
- Release assets include `SHA256SUMS.txt` and GitHub artifact attestations. See
  `docs/installation.md` for verification steps.

### Install

1. Open the DMG and drag the application into Applications.
2. This build is not Developer ID signed or notarized. On first launch, right-click the
   app and choose Open, or use System Settings → Privacy & Security → Open Anyway.
3. The Offline build uses its bundled CLI. For the Standard build:

```bash
npm i -g @deveco/deveco-code
deveco providers
```

See `docs/installation.md` for the complete guide.

### Known limitations

- macOS 12+ only; there is no Universal binary, and Windows/Linux are not supported.
- Sign-in, model calls, and the HarmonyOS knowledge base still require network access.
- DevEco Studio, HarmonyOS SDK, HDC, and emulators are not bundled.
- Auto-update, Windows, and Linux are not available yet.
- Message editing only covers user messages with text/attachments. It cannot be undone,
  and restoring files may overwrite later uncommitted changes.
- Saving CLI configuration reloads the instance and may interrupt running tasks.
