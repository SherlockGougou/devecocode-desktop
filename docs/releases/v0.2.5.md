# DevEco Code Desktop v0.2.5

发布日期：2026-11-09

## 中文

v0.2.5 增加消息图片查看与会话级权限切换，并改善长会话的导航、消息操作和中断状态展示。
普通版不内置 CLI；Offline 版继续内置固定版本 CLI。

### 版本内容

- Markdown 本地图片和工具返回的图片附件会内嵌显示，支持 PNG/JPEG/GIF/WebP/SVG/AVIF、
  `%20` 等编码路径、工作区相对路径、绝对路径和 `~`。加载失败会显示可读占位。
- 点击图片可打开大图查看器，支持缩放、拖动、适应窗口、实际大小、同消息多图切换和
  共享元素过渡；右键或查看器工具栏可复制图片、另存为。
- 远程图片复制与另存改为流式读取，在超过 32MB 前中止；图片解码失败会进入错误状态，
  不再留下裂图或泄漏 Blob URL。
- Composer 增加会话级权限选择器：“跟随 Agent / 每次询问 / 完全访问”。规则仅写入当前
  会话，不修改 CLI 配置；Agent 的通配 deny、兜底 deny 和具体命令/路径 deny 始终保留。
- 权限写入失败或已被新请求取代时会取消本次发送，避免使用新 Agent 配合旧会话权限启动
  一轮任务。切换 Agent 时的权限同步失败会恢复原 Agent。
- 消息流增加按用户轮次生成的左侧导航，可悬停展开并跳转；向上滚动时提供“最新消息”
  按钮。
- 同一分钟内的连续助手步骤合并为紧凑消息组，组尾共用一次复制操作；用户和助手消息操作
  改为带 tooltip / aria-label 的图标。
- 会话空闲后残留的 `in_progress` 待办显示为“已中断”，不再持续转圈。
- 增加前端纯逻辑测试、图片流式上限与编码路径测试，以及会话权限 PATCH 追加契约自检。

### 升级

`0.2.4` 可以直接通过应用内更新升级到 `0.2.5`；如果更新入口不可用，请手动下载本页
DMG。更早版本仍需要手动安装一次。

本次发布完成后，GitHub Releases 只保留 `v0.2.5`；旧版本不再提供下载。

### 下载

- Apple Silicon：`DevEco.Code_0.2.5_aarch64.dmg`
- Intel：`DevEco.Code_0.2.5_x64.dmg`
- Offline 版：`DevEco.Code.Offline_0.2.5_aarch64.dmg` 和
  `DevEco.Code.Offline_0.2.5_x64.dmg`

普通版需要另行安装并登录 `@deveco/deveco-code`；Offline 版内置 CLI，但仍需要网络登录
和调用模型。更新客户端会读取 `latest.json` / `latest-offline.json`、`.app.tar.gz`
和 `.sig` 资产。

### 安装

1. 打开 DMG，把 `DevEco Code.app` 或 `DevEco Code Offline.app` 拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用选择“打开”，或到
   “系统设置 → 隐私与安全性”点击“仍要打开”。
3. 普通版首次使用前安装 CLI：

```bash
npm i -g @deveco/deveco-code
deveco providers
```

完整说明见 `docs/installation.md`。

### 校验

Release 附带 `SHA256SUMS.txt`、GitHub artifact attestation 和两套更新清单。下载全部
资产后可以执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
gh release verify v0.2.5 -R SherlockGougou/devecocode-desktop
gh attestation verify "DevEco.Code_0.2.5_aarch64.dmg" -R SherlockGougou/devecocode-desktop
```

attestation 证明构建来源和资产未被替换，不替代 Apple Developer ID 签名或公证。

### 已知限制

- 仅验证 macOS 12+；不提供 Universal 二进制，也不支持 Windows 或 Linux。
- 发布包仍是 ad-hoc 签名，不是 Apple 可验证身份；更新后 macOS 的文件夹授权可能需要
  重新允许。
- 消息内嵌图片不支持 HEIC、TIFF、BMP 等格式；图片复制只支持 PNG/JPEG/GIF/WebP，
  SVG 和 AVIF 可以查看和另存。
- 会话权限只覆盖 `bash`、`external_directory`、`webfetch`、`websearch` 四类操作；
  “完全访问”不会覆盖 Agent 的硬限制。
- 从 DMG 直接运行、处于 App Translocation 或没有写入权限时无法替换应用，需要先移动到
  “应用程序”。Homebrew cask 的版本记录不会随应用内更新同步。
- 更新下载中不能取消；退出应用会中止下载。更新前正在执行的会话和内存中的排队消息会
  因重启中断。
- DevEco Studio、HarmonyOS SDK、HDC 和模拟器不随应用分发；登录、模型调用和知识库
  仍需要网络。

## English

v0.2.5 adds inline message images, a full image viewer, and session-level permission modes,
while improving navigation and message actions in long conversations. The Standard build
does not bundle the CLI; the Offline build continues to ship a pinned CLI.

### What's new

- Markdown images and image attachments returned by tools now render inline, including
  workspace-relative, absolute, `~`, and percent-encoded paths. Supported formats are
  PNG/JPEG/GIF/WebP/SVG/AVIF, with readable fallback states when loading fails.
- Clicking an image opens a viewer with zoom, pan, fit-to-window, actual-size, multi-image
  navigation within the same message, and a shared-element transition. Images can be
  copied or saved from the context menu or viewer toolbar.
- Remote image copy/save now streams the response and aborts before exceeding 32MB.
  Decode failures enter an error state instead of leaving a broken image or leaking a
  Blob URL.
- The Composer adds a session permission selector: “Follow Agent / Ask every time / Full
  access”. Rules apply only to the current session and do not modify CLI configuration.
  Agent wildcard denies, fallback denies, and specific command/path denies remain active.
- If a permission update fails or is superseded, the next prompt is cancelled rather than
  running a new Agent with stale session rules. A failed Agent-switch sync restores the
  previous Agent.
- The transcript adds user-turn navigation on the left and a latest-message button when
  scrolled up.
- Consecutive assistant steps in the same minute are grouped into a compact message group
  with one shared copy action at the end. Message actions now use icons with tooltips and
  ARIA labels.
- Leftover `in_progress` todos in an idle session are shown as interrupted instead of
  spinning forever.
- Added frontend logic tests, image streaming/path tests, and a selftest assertion for the
  session permission PATCH append contract.

### Upgrade

`0.2.4` can update to `0.2.5` in-app. If the updater is unavailable, download the DMG from
this release manually. Earlier versions still require a one-time manual install.

After this release is published, GitHub Releases will only keep `v0.2.5`; older versions
will no longer be available for download.

### Downloads

- Apple Silicon: `DevEco.Code_0.2.5_aarch64.dmg`
- Intel: `DevEco.Code_0.2.5_x64.dmg`
- Offline: `DevEco.Code.Offline_0.2.5_aarch64.dmg` and
  `DevEco.Code.Offline_0.2.5_x64.dmg`

The Standard build requires a separately installed and signed-in `@deveco/deveco-code`;
the Offline build bundles the CLI but still needs network access for sign-in and model
calls. The updater reads `latest.json` / `latest-offline.json`, `.app.tar.gz`, and `.sig`
assets.

### Install

1. Open the DMG and drag `DevEco Code.app` or `DevEco Code Offline.app` into Applications.
2. This build is not Developer ID signed or notarized. On first launch, right-click the
   app and choose Open, or use System Settings → Privacy & Security → Open Anyway.
3. For the Standard build, install the CLI first:

```bash
npm i -g @deveco/deveco-code
deveco providers
```

See `docs/installation.md` for the complete guide.

### Verification

Each release includes `SHA256SUMS.txt`, GitHub artifact attestations, and both update
manifests. After downloading all assets:

```bash
shasum -a 256 -c SHA256SUMS.txt
gh release verify v0.2.5 -R SherlockGougou/devecocode-desktop
gh attestation verify "DevEco.Code_0.2.5_aarch64.dmg" -R SherlockGougou/devecocode-desktop
```

Attestations prove the build origin and that assets were not replaced; they do not replace
Apple Developer ID signing or notarization.

### Known limitations

- macOS 12+ only; there is no Universal binary, and Windows/Linux are not supported.
- The release is ad-hoc signed, not an Apple-verifiable identity. macOS folder permissions
  may need to be granted again after an update.
- Inline images do not support HEIC, TIFF, or BMP. Clipboard copy supports
  PNG/JPEG/GIF/WebP; SVG and AVIF can be viewed and saved.
- Session permissions only cover `bash`, `external_directory`, `webfetch`, and
  `websearch`; “Full access” does not override Agent hard limits.
- Updates cannot replace an app running from a DMG, App Translocation, or a read-only
  location; move it to Applications first. Homebrew cask records do not track in-app
  updates.
- Downloads cannot be cancelled; quitting the app aborts the download. Running sessions
  and in-memory queued messages are interrupted by the restart.
- DevEco Studio, the HarmonyOS SDK, HDC, and emulators are not bundled. Sign-in, model
  calls, and the knowledge base still require network access.
