# DevEco Code Desktop v0.2.9

发布日期：2026-11-16

## 中文

v0.2.9 调整子代理会话的展示方式：子代理不再进入工作区会话列表，父会话的任务详情可以
直接查看完整对话。普通版不内置 CLI；Offline 版继续内置固定版本 CLI。

### 版本内容

- 工作区侧栏只展示根会话；CLI 返回的 `parentID` 和旧数据中的 `(@agent subagent)`
  标题标记都会被识别为子代理会话。初始化列表、实时事件、搜索、刷新和未读标记使用同一
  规则，迟到的子会话事件也不会重新插回侧栏。
- 子代理会话仍保留在父会话的任务面板中。打开任务卡片后新增“对话/活动”页签，默认显示
  完整对话，活动摘要仍可切换查看。
- 完整对话按需读取，复用主会话的消息、思考折叠、工具卡片、图片、附件查看和 Markdown
  渲染。任务列表仍只预取最近消息生成摘要，不会为每个子任务反复拉取完整历史。
- 实时消息、工具调用和状态事件继续更新已打开的子任务对话；切换会话时清理子任务快照，
  避免把上一会话的内容带到新任务里。
- 补充子会话识别、根列表过滤和标题清理测试；前端测试 37 项、Rust 测试 114 项通过。

### 升级

`0.2.8` 可以直接通过应用内更新升级到 `0.2.9`；如果更新入口不可用，请手动下载本页
DMG。更早版本仍建议手动安装一次。

本次发布完成后，GitHub Releases 只保留 `v0.2.9`；旧版本不再提供下载。

### 下载

- Apple Silicon：`DevEco.Code_0.2.9_aarch64.dmg`
- Intel：`DevEco.Code_0.2.9_x64.dmg`
- Offline 版：`DevEco.Code.Offline_0.2.9_aarch64.dmg` 和
  `DevEco.Code.Offline_0.2.9_x64.dmg`

普通版需要另行安装并登录 `@deveco/deveco-code`；Offline 版内置 CLI，但仍需要网络登录
和调用模型。更新客户端会读取 `latest.json` / `latest-offline.json`、`.app.tar.gz`
和 `.sig` 资产。

### 安装

1. 打开 DMG，把 `DevEco Code.app` 或 `DevEco Code Offline.app` 拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用选择“打开”，或到
   “系统设置 → 隐私与安全性”点击“仍要打开”。
3. 普通版首次使用前安装 CLI：

```bash
npm i -g @deveco/deveco-code
deveco providers
```

完整说明见 `docs/installation.md`。

### 校验

Release 附带 `SHA256SUMS.txt`、GitHub artifact attestation 和两套更新清单。下载全部
资产后可以执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
gh release verify v0.2.9 -R SherlockGougou/devecocode-desktop
gh attestation verify "DevEco.Code_0.2.9_aarch64.dmg" -R SherlockGougou/devecocode-desktop
```

attestation 证明构建来源和资产未被替换，不替代 Apple Developer ID 签名或公证。

### 已知限制

- 子代理对话目前只读，不能直接编辑子代理消息或继续该子会话；需要继续工作时，请在父
  会话里重新发起任务。
- 完整对话按需读取；服务不可用或请求失败时，任务详情显示错误，已缓存的活动摘要仍可
  切换查看。
- 子会话识别依赖 CLI 的 `parentID` 或历史标题标记；两者都缺失的极旧数据仍可能作为
  普通会话显示。
- 仅验证 macOS 12+；不提供 Universal 二进制，也不支持 Windows 或 Linux。
- 发布包仍是 ad-hoc 签名，不是 Apple 可验证身份；更新后 macOS 的文件夹授权可能需要
  重新允许。
- 从 DMG 直接运行、处于 App Translocation 或没有写入权限时无法替换应用，需要先移动到
  “应用程序”。Homebrew cask 的版本记录不会随应用内更新同步。
- 更新下载中不能取消；退出应用会中止下载。更新前正在执行的会话和内存中的排队消息会
  因重启中断。
- DevEco Studio、HarmonyOS SDK、HDC 和模拟器不随应用分发；登录、模型调用和知识库
  仍需要网络。

## English

v0.2.9 changes how subagent sessions are presented: they no longer appear in the
workspace session list, and the parent session's task detail can show their full
conversation. The Standard build does not bundle the CLI; the Offline build continues to
ship a pinned CLI.

### What's new

- The workspace sidebar now lists only root sessions. Sessions with a CLI `parentID` or
  the legacy `(@agent subagent)` title marker are treated as subagent sessions. Initial
  loading, live events, search, refresh, and unread markers share the same rule, so a
  late child event cannot reappear in the sidebar.
- Subagent sessions remain in the parent session's task panel. Opening a task card now
  shows Conversation and Activity tabs, with the full conversation selected by default.
- The full transcript is loaded on demand and reuses the main conversation's messages,
  reasoning collapse, tool cards, image viewer, attachments, and Markdown rendering. The
  task list still prefetches only recent messages for summaries, so opening the panel
  does not repeatedly pull every child's full history.
- Live message, tool, and status events continue to update an open child transcript.
  Switching sessions clears the child snapshot so content from the previous session
  cannot leak into a new task.
- Added tests for subagent detection, root-list filtering, and title cleanup. The
  frontend suite has 37 tests and the Rust suite has 114 tests.

### Upgrade

`0.2.8` can update to `0.2.9` in-app. If the updater is unavailable, download the DMG from
this release manually. Earlier versions should still perform a one-time manual install.

After this release is published, GitHub Releases will only keep `v0.2.9`; older versions
will no longer be available for download.

### Downloads

- Apple Silicon: `DevEco.Code_0.2.9_aarch64.dmg`
- Intel: `DevEco.Code_0.2.9_x64.dmg`
- Offline: `DevEco.Code.Offline_0.2.9_aarch64.dmg` and
  `DevEco.Code.Offline_0.2.9_x64.dmg`

The Standard build requires a separately installed and signed-in `@deveco/deveco-code`;
the Offline build bundles the CLI but still needs network access for sign-in and model
calls. The updater reads `latest.json` / `latest-offline.json`, `.app.tar.gz`, and `.sig`
assets.

### Install

1. Open the DMG and drag `DevEco Code.app` or `DevEco Code Offline.app` into Applications.
2. This build is not Developer ID signed or notarized. On first launch, right-click the
   app and choose Open, or use System Settings → Privacy & Security → Open Anyway.
3. For the Standard build, install the CLI first:

```bash
npm i -g @deveco/deveco-code
deveco providers
```

See `docs/installation.md` for the full guide.

### Verify

The release includes `SHA256SUMS.txt`, GitHub artifact attestations, and both updater
manifests. After downloading all assets:

```bash
shasum -a 256 -c SHA256SUMS.txt
gh release verify v0.2.9 -R SherlockGougou/devecocode-desktop
gh attestation verify "DevEco.Code_0.2.9_aarch64.dmg" -R SherlockGougou/devecocode-desktop
```

Attestations prove build provenance and asset integrity; they do not replace Apple
Developer ID signing or notarization.

### Known limitations

- A child transcript is currently read-only. Editing a child message or continuing that
  child session directly is not supported; start a new task from the parent session.
- The full transcript is loaded on demand. If the service is unavailable or the request
  fails, the task detail shows an error and the cached Activity view remains available.
- Subagent detection relies on the CLI `parentID` or the legacy title marker. Very old
  data with neither may still appear as an ordinary session.
- Validated on macOS 12+ only; there is no Universal binary and no Windows or Linux
  support.
- Builds remain ad-hoc signed rather than using a verifiable Apple identity; macOS folder
  permissions may need to be granted again after an update.
- Running directly from the DMG, App Translocation, or a read-only location prevents app
  replacement; move the app to Applications first. Homebrew cask versions do not track
  in-app updates.
- An in-progress update download cannot be cancelled; quitting the app aborts it. Running
  sessions and queued messages are interrupted by the restart.
- DevEco Studio, the HarmonyOS SDK, HDC, and emulators are not bundled; sign-in, model
  calls, and the knowledge base still require network access.
