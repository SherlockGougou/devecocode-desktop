# DevEco Code Desktop v0.2.1

发布日期：2026-11-08

## 中文

本版本提供两种 macOS 安装包：

- **普通版**：不内置 CLI，应用体积较小；需要先安装并登录
  `@deveco/deveco-code`。
- **Offline 版**：内置固定版本 DevEco Code CLI `0.2.5`，适合不想在机器上另行安装 CLI
  的用户。应用首次启动会将 CLI 资源复制到自己的数据目录。

### 版本内容

- 设置页升级为 CLI 配置中心：支持全局/当前工作区作用域、常用字段表单和高级 JSONC，
  覆盖 Provider/模型、MCP、Agent/Command、权限、Skills、Plugins 与启动参数。
- CLI 配置写入增加 base hash 冲突检测、原子替换、备份恢复和实例重载；密钥默认脱敏。
- 内嵌 `deveco-desktop-device` skill，并向 CLI 注入已定位的 `HDC`，让 Agent 可以完成
  HarmonyOS 设备截图、布局检查、输入、应用控制和日志采集。
- 右栏重构为变更、文件、任务、设备四个标签，支持工作区/会话双来源 diff、目录树、
  统一 diff 查看器、文件搜索和系统预览。
- 新增底部终端：通过 CLI `/pty` 打开当前工作区的本地 Shell，支持 `⌘J` 展开、拖高、
  清屏、重开和关闭回收。
- 状态栏显示 Token 总量、缓存命中、上下文占用和输出速度（TPS）；输出速度排除工具执行等待。
- 历史用户消息可原位编辑：先用 `revert` 还原工作区，再按原 Agent/模型重新请求；
  提交前会展示影响范围，失败时按服务端状态恢复。
- 执行中 Enter 排队、`⌘Enter` 发送引导；`session.idle` 后按会话 FIFO 投递，停止时暂停
  队列，错过当前轮时发送 synthetic 继续消息。
- 打开会话与重连时用 `/session/status` 校准执行态；残留工具/思考显示为“已中断”，
  侧栏显示执行中加载指示和结束未查看的未读圆点。
- 对齐 macOS 红绿灯与自绘顶栏基线，修正标题栏重叠和窄窗口布局。

### 下载

- Apple Silicon：选择文件名带 `aarch64` 的 DMG。
- Intel：选择文件名带 `x64` 的 DMG。
- 两个架构都提供 `DevEco Code` 和 `DevEco Code Offline` 两种包。

### 安装

1. 打开 DMG，将应用拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用并选择“打开”，或到
   “系统设置 → 隐私与安全性”点击“仍要打开”。
3. Offline 版直接使用内置 CLI；普通版先安装并登录 CLI：

```bash
npm i -g @deveco/deveco-code
deveco providers
```

完整说明见仓库的 `docs/installation.md`。

### 已知限制

- macOS 12+，当前只验证 macOS；不提供 Universal 二进制。
- 登录、模型调用和 HarmonyOS 知识库仍需要网络。
- DevEco Studio、HarmonyOS SDK、HDC、模拟器不随应用分发。
- 暂不支持自动更新、Windows 和 Linux。
- 历史消息编辑只支持用户消息及文本/附件内容；发送后不可撤销，文件还原可能覆盖之后的
  未提交修改。
- 保存 CLI 配置会重载实例，正在运行的任务可能被中断。

## English

This release provides two macOS packages:

- **Standard**: does not bundle the CLI and has a smaller download. Install and sign in to
  `@deveco/deveco-code` separately.
- **Offline**: bundles DevEco Code CLI `0.2.5` and copies its runtime into the application
  data directory on first launch. Suitable when a global CLI installation is not desired.

### What's new

- The settings page is now a CLI configuration center with global/workspace scopes, common
  field forms, and advanced JSONC editing for providers/models, MCP, agents/commands,
  permissions, skills, plugins, and launch options.
- CLI configuration writes now use base-hash conflict checks, atomic replacement, backups,
  instance reloads, and masked secret values.
- A bundled `deveco-desktop-device` skill and detected `HDC` path let agents take HarmonyOS
  screenshots, inspect layouts, send input, control apps, and collect device logs.
- The right panel is reorganized into Changes, Files, Tasks, and Device tabs, with
  workspace/session diffs, a directory tree, a unified diff viewer, file search, and system
  preview.
- A bottom terminal opens a local shell for the current workspace through the CLI `/pty`
  contract, with `⌘J`, resize, clear, restart, and close cleanup.
- The status bar now reports total tokens, cache hits, context usage, and output speed (TPS),
  excluding time spent waiting on tool execution.
- User messages can be edited in place: the CLI `revert` restores the workspace, then the
  message is resent with the original agent/model after showing the impact scope.
- While a session is running, Enter queues a message and `⌘Enter` steers it. Queued messages
  are delivered FIFO after `session.idle`; stopping pauses the queue, and missed turns use a
  synthetic continuation message.
- Opening or reconnecting a session reconciles execution state through `/session/status`;
  stale tools/reasoning are shown as interrupted, with running indicators and unread dots in
  the sidebar.
- macOS traffic lights are aligned with the custom titlebar baseline, fixing overlap and
  narrow-window layout issues.

### Downloads

- Apple Silicon: choose the DMG with `aarch64` in its filename.
- Intel: choose the DMG with `x64` in its filename.
- Both architectures include the Standard and Offline packages.

### Install

1. Open the DMG and drag the application into Applications.
2. This build is not Developer ID signed or notarized. On first launch, right-click the app and
   choose Open, or use System Settings → Privacy & Security → Open Anyway.
3. The Offline build uses its bundled CLI. For the Standard build:

```bash
npm i -g @deveco/deveco-code
deveco providers
```

See `docs/installation.md` for the complete guide.

### Known limitations

- macOS 12+ only; there is no Universal binary, and Windows/Linux are not supported.
- Sign-in, model calls, and the HarmonyOS knowledge base still require network access.
- DevEco Studio, HarmonyOS SDK, HDC, and emulators are not bundled.
- Auto-update, Windows, and Linux are not available yet.
- Message editing only covers user messages with text/attachments. It cannot be undone, and
  restoring files may overwrite later uncommitted changes.
- Saving CLI configuration reloads the instance and may interrupt running tasks.
