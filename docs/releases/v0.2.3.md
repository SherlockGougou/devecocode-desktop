# DevEco Code Desktop v0.2.3

发布日期：2026-11-08

## 中文

v0.2.3 是首个内置应用内更新的版本。普通版和 Offline 版都可以从 GitHub Releases 检查
新版本，由用户确认下载并重启；更新包使用 Ed25519 签名，不依赖 Apple Developer ID。
本版本同时包含 Homebrew tap、英文 README、Dependabot 与设置持久化修复。

### 版本内容

- 新增应用内更新：启动约 8 秒后静默检查一次，之后每 24 小时检查一次；可在
  “设置 → 关于与更新”关闭自动检查，也可从应用菜单或菜单栏手动检查。
- 发现新版本后显示顶部横幅，支持下载进度、安装完成提示和重启确认；安装期间可以继续
  使用应用，重启前若正在执行或有排队消息会再次确认。
- 普通版读取 `latest.json`，Offline 版读取 `latest-offline.json`；Offline 版更新会
  同时替换内置 CLI。
- 更新包使用 `TAURI_SIGNING_PRIVATE_KEY` 签名，客户端固定公钥并启用
  `requireSignedVersion`；Release 额外提供 `.app.tar.gz` 和 `.sig`。
- 修复桌面端设置保存只更新内存、不写入 `config.json` 的问题；后端自愈时也不会再覆盖
  启动后保存的配置。
- 新增完整英文 README、Dependabot 分组更新与自动合并、独立 Homebrew tap 及 cask 更新
  workflow；Release 继续使用 draft-first、`SHA256SUMS.txt`、artifact attestation 和
  immutable release。

### 首次升级说明

`0.2.2` 及更早版本不包含 updater，必须手动下载并安装一次 `0.2.3`。从 `0.2.3` 开始，
后续版本可以通过应用内更新安装。普通版只更新桌面端，CLI 仍按自己的方式升级；Offline
版更新会替换内置 CLI。自动检查默认开启，不需要时可以在设置中关闭。

### 下载

- Apple Silicon：`DevEco.Code_0.2.3_aarch64.dmg`；
- Intel：`DevEco.Code_0.2.3_x64.dmg`；
- Offline 版对应 `DevEco.Code.Offline_0.2.3_aarch64.dmg` 和
  `DevEco.Code.Offline_0.2.3_x64.dmg`。

普通版需要另行安装并登录 `@deveco/deveco-code`；Offline 版内置固定版本 CLI，但仍需要
网络登录和调用模型。更新客户端还会读取 `latest.json` / `latest-offline.json`、
`.app.tar.gz` 和 `.sig` 资产。

### 安装

1. 打开 DMG，把 `DevEco Code.app` 或 `DevEco Code Offline.app` 拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用选择“打开”，或到
   “系统设置 → 隐私与安全性”点击“仍要打开”。
3. 普通版首次使用前安装 CLI：

```bash
npm i -g @deveco/deveco-code
deveco providers
```

完整说明见 `docs/installation.md`。

### 校验

Release 附带 `SHA256SUMS.txt`、GitHub artifact attestation 和两套更新清单。下载全部
资产后可以执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
gh release verify v0.2.3 -R SherlockGougou/devecocode-desktop
gh attestation verify "DevEco.Code_0.2.3_aarch64.dmg" -R SherlockGougou/devecocode-desktop
```

attestation 证明构建来源和资产未被替换，不替代 Apple Developer ID 签名或公证。

### 已知限制

- 仅验证 macOS 12+；不提供 Universal 二进制，也不支持 Windows 或 Linux。
- 发布包仍是 ad-hoc 签名，不是 Apple 可验证身份；更新后 macOS 的文件夹授权可能需要
  重新允许。
- 从 DMG 直接运行、处于 App Translocation 或没有写入权限时无法替换应用，需要先移动到
  “应用程序”。Homebrew cask 的版本记录不会随应用内更新同步，可以继续用
  `brew upgrade --cask` 重装。
- 更新下载中不能取消；退出应用会中止下载。更新前正在执行的会话和内存中的排队消息会
  因重启中断。
- DevEco Studio、HarmonyOS SDK、HDC 和模拟器不随应用分发；登录、模型调用和知识库
  仍需要网络。
- 历史消息编辑只支持用户消息及文本/附件内容，发送后不可撤销，文件还原可能覆盖之后的
  未提交修改。

## English

v0.2.3 is the first release with in-app updates. Both the Standard and Offline builds can
check GitHub Releases for a newer version, download it after user confirmation, and
restart to install it. Update bundles are signed with a self-managed Ed25519 key and do
not require an Apple Developer ID. This release also includes the Homebrew tap, an English
README, Dependabot automation, and a settings persistence fix.

### What's new

- In-app updates check once about 8 seconds after launch and every 24 hours afterward.
  Automatic checks can be disabled in Settings → About & Updates; manual checks are
  available from the app menu and menu bar.
- A top banner shows the new version, download progress, installation state, and restart
  confirmation. The app remains usable during download and installation. A second
  confirmation appears before restart if a session is running or queued messages exist.
- The Standard build reads `latest.json`; the Offline build reads `latest-offline.json`.
  Updating the Offline build also replaces its bundled CLI.
- Update bundles are signed with `TAURI_SIGNING_PRIVATE_KEY`; the client pins the public
  key and enables `requireSignedVersion`. Releases also include `.app.tar.gz` and `.sig`
  assets.
- Fixed desktop settings being saved only in memory instead of `config.json`; backend
  recovery no longer overwrites settings saved after launch.
- Added the full English README, grouped Dependabot updates and auto-merge, the standalone
  Homebrew tap and cask update workflow. Releases still use draft-first publishing,
  `SHA256SUMS.txt`, artifact attestations, and immutable releases.

### First upgrade

`0.2.2` and earlier do not contain the updater and must install `0.2.3` manually once.
Starting with `0.2.3`, later versions can be installed in-app. The Standard build only
updates the desktop app; the CLI keeps its own upgrade path. The Offline build also
replaces its bundled CLI. Automatic checks are enabled by default and can be disabled in
Settings.

### Downloads

- Apple Silicon: `DevEco.Code_0.2.3_aarch64.dmg`;
- Intel: `DevEco.Code_0.2.3_x64.dmg`;
- Offline: `DevEco.Code.Offline_0.2.3_aarch64.dmg` and
  `DevEco.Code.Offline_0.2.3_x64.dmg`.

The Standard build requires a separately installed `@deveco/deveco-code`; the Offline
build bundles a pinned CLI but still needs network access for sign-in and model calls.
The updater also reads `latest.json` / `latest-offline.json`, `.app.tar.gz`, and `.sig`
assets.

### Install

1. Open the DMG and drag `DevEco Code.app` or `DevEco Code Offline.app` into Applications.
2. This build is not Developer ID signed or notarized. On first launch, right-click the
   app and choose Open, or use System Settings → Privacy & Security → Open Anyway.
3. For the Standard build, install the CLI first:

```bash
npm i -g @deveco/deveco-code
deveco providers
```

See `docs/installation.md` for the complete guide.

### Verification

Each release includes `SHA256SUMS.txt`, GitHub artifact attestations, and both update
manifests. After downloading all assets:

```bash
shasum -a 256 -c SHA256SUMS.txt
gh release verify v0.2.3 -R SherlockGougou/devecocode-desktop
gh attestation verify "DevEco.Code_0.2.3_aarch64.dmg" -R SherlockGougou/devecocode-desktop
```

Attestations prove the build origin and that assets were not replaced; they do not replace
Apple Developer ID signing or notarization.

### Known limitations

- macOS 12+ only; there is no Universal binary, and Windows/Linux are not supported.
- The release is ad-hoc signed, not an Apple-verifiable identity. macOS folder permissions
  may need to be granted again after an update.
- Updates cannot replace an app running from a DMG, App Translocation, or a read-only
  location; move it to Applications first. Homebrew cask records do not track in-app
  updates; `brew upgrade --cask` remains available.
- Downloads cannot be cancelled; quitting the app aborts the download. Running sessions
  and in-memory queued messages are interrupted by the restart.
- DevEco Studio, the HarmonyOS SDK, HDC, and emulators are not bundled. Sign-in, model
  calls, and the knowledge base still require network access.
- Message editing only covers user messages with text/attachments. It cannot be undone,
  and restoring files may overwrite later uncommitted changes.
