# DevEco Code Desktop v0.2.0

发布日期：2026-11-07

## 中文

本版本提供两种 macOS 安装包：

- **普通版**：不内置 CLI，应用体积较小；需要先安装并登录
  `@deveco/deveco-code`。
- **Offline 版**：内置固定版本 DevEco Code CLI `0.2.5`，适合不想在机器上另行安装 CLI
  的用户。应用首次启动会将 CLI 资源复制到自己的数据目录。

### 版本内容

- 自研三栏桌面界面，驱动本机 CLI 的 HTTP + SSE 契约。
- 工作区、会话搜索、归档、流式消息、思考/工具调用聚合与子代理待办。
- `@` 文件引用、附件、Markdown、文件预览、变更面板、Git 提交/推送。
- HarmonyOS 设备截图、菜单栏、系统通知和全局右键菜单。
- Offline 版将 CLI 配置、会话数据库、缓存和认证隔离到应用数据目录，并关闭内置 CLI 自动更新。

### 下载

- Apple Silicon：选择文件名带 `aarch64` 的 DMG。
- Intel：选择文件名带 `x64` 的 DMG。
- 两个架构都提供 `DevEco Code` 和 `DevEco Code Offline` 两种包。

### 安装

1. 打开 DMG，将应用拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用并选择“打开”，或到
   “系统设置 → 隐私与安全性”点击“仍要打开”。
3. Offline 版直接使用内置 CLI；普通版先安装并登录 CLI：

```bash
npm i -g @deveco/deveco-code
deveco providers
```

完整说明见仓库的 `docs/installation.md`。

### 已知限制

- macOS 12+，当前只验证 macOS。
- 登录、模型调用和 HarmonyOS 知识库仍需要网络。
- DevEco Studio、HarmonyOS SDK、HDC、模拟器不随应用分发。
- 暂不支持自动更新、Windows 和 Linux。

## English

This release provides two macOS packages:

- **Standard**: does not bundle the CLI and has a smaller download. Install and sign in to
  `@deveco/deveco-code` separately.
- **Offline**: bundles DevEco Code CLI `0.2.5` and copies its runtime into the application
  data directory on first launch. Suitable when a global CLI installation is not desired.

### What's included

- A native three-column desktop workspace backed by the local CLI HTTP + SSE contract.
- Workspaces, session search and archive, streaming messages, reasoning/tool aggregation, and
  subagent/todo views.
- `@` file references, attachments, Markdown, file preview, diff, and explicit Git commit/push.
- HarmonyOS device screenshots, menu bar, system notifications, and context menus.
- The Offline build isolates CLI config, session database, cache, and credentials from the
  system CLI, and disables CLI auto-update.

### Downloads

- Apple Silicon: choose the DMG with `aarch64` in its filename.
- Intel: choose the DMG with `x64` in its filename.
- Both architectures include the Standard and Offline packages.

### Install

1. Open the DMG and drag the application into Applications.
2. This build is not Developer ID signed or notarized. On first launch, right-click the app and
   choose Open, or use System Settings → Privacy & Security → Open Anyway.
3. The Offline build uses its bundled CLI. For the Standard build:

```bash
npm i -g @deveco/deveco-code
deveco providers
```

See `docs/installation.md` for the complete guide.

### Known limitations

- macOS 12+ only; Windows and Linux are not supported.
- Sign-in, model calls, and the HarmonyOS knowledge base still require network access.
- DevEco Studio, HarmonyOS SDK, HDC, and emulators are not bundled.
- Auto-update, Windows, and Linux are not available yet.
