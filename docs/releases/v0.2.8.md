# DevEco Code Desktop v0.2.8

发布日期：2026-11-14

## 中文

v0.2.8 增加 macOS 本地语音输入、输入草稿与会话缓存，并改进长会话浏览、退出确认和
更新入口。普通版不内置 CLI；Offline 版继续内置固定版本 CLI。

### 版本内容

- Composer 支持 macOS 本地语音输入：点击麦克风，或在输入框聚焦时长按左 `⌥` 开始，
  录音期间在输入框上方显示实时转写，停止后把文字插入原光标/选区，可撤销 6 秒。
  识别强制在本机完成，不可用时直接报错，不回退 Apple 在线识别；录音不写入磁盘，
  单次约 55 秒自动结束。
- 设置新增“语音”页：显示麦克风与语音识别权限、可用的本地识别语言、长按左 `⌥` 开关，
  并提供系统隐私设置入口。`Info.plist` 和 Hardened Runtime entitlement 补齐隐私文案
  与麦克风能力。
- 未发送文字按“工作区 + 会话”保存为草稿，切换会话、重启应用后恢复；发送成功或清空
  输入时删除。`@` 引用 chip 随草稿文本一起恢复。
- 最近访问的 5 个会话保留在内存中，切回时先显示缓存并在后台刷新；刷新失败保留缓存并
  提示，切换会话后忽略旧请求的结果。
- 长会话默认渲染最近 100 条消息，可分批加载更早历史；从轮次导航跳转到更早消息时自动
  展开，提交新消息后回到最新消息。
- Dock 图标显示未读会话数量（超过 99 显示 `99+`），打开全部未读会话后清除；删除会话
  或从侧栏移除工作区时会同步清理对应未读标记。
- 关闭主窗口或从托盘退出前会确认；确认后停止本应用启动的本地服务。`⌘Q` 与系统菜单的
  “退出”仍由 macOS 直接结束进程，不经过应用确认。
- 应用菜单和菜单栏的“检查更新…”改为直接后台检查并提示结果，不再跳转设置页。
- 修正语音输入在 macOS 12 上可能因系统不提供 `addsPunctuation` 选项而崩溃的问题。
- 性能与稳定性：消息查找改用索引、Markdown 组件缓存渲染结果，并补充会话缓存、合并
  与草稿逻辑测试；前端测试 33 项、Rust 测试 114 项通过。

本次发布完成后，GitHub Releases 只保留 `v0.2.8`；旧版本不再提供下载。

### 安装

1. 打开 DMG，把 `DevEco Code.app` 或 `DevEco Code Offline.app` 拖入“应用程序”。
2. 当前构建没有 Developer ID 签名，也没有公证；首次打开请右键应用选择“打开”，或到

```bash

```

完整说明见 `docs/installation.md`。

### 已知限制

- 语音输入只支持 System Speech 框架报告支持本地识别的语言；应用不下载模型，也不
  回退 Apple 在线识别。系统语言不可用时需要在“设置 → 语音”中手动选择。
- 语音权限可能随 ad-hoc 重新签名而重置，重新授权不代表应用设置丢失。
- 语音输入单次约 55 秒自动结束，不做跨段连续识别；没有全局快捷键，长按左 `⌥` 仅在
  Composer 聚焦时生效。
- 仅验证 macOS 12+；不提供 Universal 二进制，也不支持 Windows 或 Linux。
- 发布包仍是 ad-hoc 签名，不是 Apple 可验证身份；更新后 macOS 的文件夹授权可能需要
  重新允许。
- 从 DMG 直接运行、处于 App Translocation 或没有写入权限时无法替换应用，需要先移动到
  “应用程序”。Homebrew cask 的版本记录不会随应用内更新同步。
- 更新下载中不能取消；退出应用会中止下载。更新前正在执行的会话和内存中的排队消息会
  因重启中断。
- DevEco Studio、HarmonyOS SDK、HDC 和模拟器不随应用分发；登录、模型调用和知识库
  仍需要网络。

## English

v0.2.8 adds local macOS voice input, composer drafts, and session caching, and improves
long-conversation browsing, quit confirmation, and the update entry point. The Standard
build does not bundle the CLI; the Offline build continues to ship a pinned CLI.

### What's new

- The composer supports local macOS speech input. Click the microphone, or hold the left
  `⌥` key while the composer is focused, to record; a live transcript appears above the
  composer, and the final text is inserted at the original caret or selection with a
  six-second undo. Recognition is forced on-device and reports an error instead of
  falling back to Apple's online service. Audio is never written to disk, and a session
  stops automatically after about 55 seconds.
- A new Voice settings page shows microphone and speech-recognition permissions, the
  locales available for on-device recognition, and the hold-`⌥` toggle, with links to
  system privacy settings. `Info.plist` and the Hardened Runtime entitlement now declare
  the privacy strings and microphone capability.
- Unsent composer text is stored per workspace and session and restored after switching
  sessions or restarting the app. Drafts are removed after a successful send or when the
  composer is cleared, and `@` reference chips are restored with the draft text.
- The five most recently opened sessions stay in memory: switching back shows the cached
  transcript immediately and refreshes in the background. A failed refresh keeps the
  cache and shows a notice, and stale responses are ignored after switching sessions.
- Long conversations render the latest 100 messages by default and can load earlier
  history in batches. Jumping to an older turn expands it automatically, and submitting
  a new message returns to the latest message.
- The Dock icon shows the number of unread sessions (`99+` beyond 99) and clears the
  badge once every unread session has been opened. Deleting a session or removing a
  workspace also drops its unread marker.
- Closing the main window or quitting from the tray now asks for confirmation and stops
  the local service owned by the app. Pressing `⌘Q` or using the system Quit menu item
  still terminates the process directly without the in-app confirmation.
- “Check for Updates…” in the app menu and menu bar now checks in the background and
  reports the result instead of opening settings.
- Fixed a macOS 12 crash caused by the system not providing the `addsPunctuation` option.
- Performance and reliability: indexed message lookups, memoized Markdown rendering, and
  additional tests for session caching, reconciliation, and drafts. The frontend suite
  has 33 tests and the Rust suite has 114 tests.

will no longer be available for download.

### Known limitations

- Voice input only supports locales that the Speech framework reports for on-device
  recognition. The app does not download models and does not fall back to Apple's online
  service. If the system language is unavailable, choose another locale in Settings →
  Voice.
- Voice permissions may reset when the ad-hoc signature changes; that is not lost app
  settings.
- Voice input stops automatically after about 55 seconds and does not recognize across
  segments. There is no global shortcut; holding the left `⌥` key only works while the
  composer is focused.
- Validated on macOS 12+ only; there is no Universal binary and no Windows or Linux
  support.
- Builds remain ad-hoc signed rather than using a verifiable Apple identity; macOS folder
  permissions may need to be granted again after an update.
- Running directly from the DMG, App Translocation, or a read-only location prevents app
  replacement; move the app to Applications first. Homebrew cask versions do not track
  in-app updates.
- An in-progress update download cannot be cancelled; quitting the app aborts it. Running
  sessions and queued messages are interrupted by the restart.
- `⌘Q` and the system Quit menu item bypass the in-app confirmation and end the process
  directly; close the window or quit from the tray menu to see the confirmation.
- DevEco Studio, the HarmonyOS SDK, HDC, and emulators are not bundled; sign-in, model
  calls, and the knowledge base still require network access.
